# steamboatamps.com — WordPress block theme rebuild

Mockup: `design-system/mockups/steamboat-home.png` (approved). Root CLAUDE.md rules apply.

## Environment

Same setup as robin-guitars (wp-env/LocalWP from live export). Theme in
`theme/steamboat-2026/`, tokens from `design-system/`.

## Homepage build order (matches mockup)

1. Hero — "Built different. / Played Loud." (first line accent), intro copy
   ("Hand built tube amplifiers from Houston, Texas…"), `Our amplifiers` CTA,
   Texas lockup, Steamboat Classic 18 photo with MODEL SHOWN chip.
2. The Workshop band (cream) — eyebrow "THE WORKSHOP ————", headline "Built by
   hand, Back by expertise.", copy, `Learn More` CTA, 3-image collage (chassis
   internals, jig, green head). Source photos from their Instagram archive or
   request originals (asset audit).
3. Amp lineup strip — 4 product photos (red head, black head, tweed combo,
   cabinet) linking to Amps/Cabinets pages.
4. Footer — four-brand band + NAP + **public hours** (Tue–Fri 11–6, Sat 12–4)
   + FB/IG.

## Interior pages

Amps, Cabinets, Custom, Repairs, Contact, Request a Quote.

- **Repairs is a first-class page**, not an afterthought: 15+ years as Houston's
  top tube-amp repair shop, drop-off hours, address, what they service (tube
  amps, guitars, limited pedal/cab work). The mockup nav includes Repairs —
  give it real weight.
- "Making Houston louder since 2009" — keep this line somewhere on the site.

## Site-specific hard rules

- Purge every asset reference to robinguitars.com/wp-content and to
